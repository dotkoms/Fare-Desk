# OpenSky Network (anonymous, free)

Public ADS-B observations. Useful as a supporting signal that a route is actually flying.

- Base: https://opensky-network.org/api/
- Anonymous access is rate-limited (no account needed for light use).
- Example: states in a bounding box or flight list by ICAO24.
- Not a fare source. Use only to sanity-check coverage or "is this route operating?"

See docs/25 for the planned supporting-signal role. Do not rely on it for pricing.
